# T1059.001 — PowerShell with Encoded Command

## MITRE ATT&CK

- **Technique ID:** T1059.001
- **Tactic:** Execution
- **Platform:** Windows

## Why Attackers Use This

Attackers hide malicious commands in Base64 encoding to:
- Evade plaintext inspection by security tools
- Obfuscate intent from human analysts
- Bypass simple string-based detections

PowerShell's `-EncodedCommand` flag accepts Base64-encoded UTF-16LE strings. Legitimate use is rare in most environments — it's a strong indicator of malicious intent.

## Attack Simulation

Run on Windows Server 2019:

```powershell
$cmd = "whoami"
$bytes = [System.Text.Encoding]::Unicode.GetBytes($cmd)
$encoded = [Convert]::ToBase64String($bytes)
powershell.exe -EncodedCommand $encoded
